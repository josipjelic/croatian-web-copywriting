# CLAUDE.md

This repo is the source of the `croatian-web-copywriting` skill
(`skills/croatian-web-copywriting/`). Projects that use it load it read-only from the
plugin, so every rule change is made here and pushed to `main`.

When a copy correction should become a rule, follow
[`skills/croatian-web-copywriting/references/learning-from-corrections.md`](skills/croatian-web-copywriting/references/learning-from-corrections.md).
It ships with the skill, so the same procedure runs in every project that uses it.
